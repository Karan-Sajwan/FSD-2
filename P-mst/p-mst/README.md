# Shopping Cart Indicator (React)

## Aim
To develop a simple React application that implements a shopping cart indicator where users can add items to a cart and dynamically update the total item count using React state and component communication.

## 🎯 Learning Outcomes
1. Understand how to create and organize React components in a project.
2. Learn how to manage and update state using the `useState` hook.
3. Understand how to pass data and functions between components using props.
4. Gain experience in handling user events and updating the UI dynamically in React.
